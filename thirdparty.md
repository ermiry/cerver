# Third-party code

The code of other projects that cerver includes, with its license. Each file keeps its copyright and permission
notice.

| Code | Files | Version | License | Changes |
|---|---|---|---|---|
| [llhttp](https://github.com/nodejs/llhttp) | `include/cerver/http/parser/`, `src/cerver/http/parser/` | 9.4.3 | MIT, Copyright Fedor Indutny, 2018 | Split in `llhttp.h`, `helpers.h` and `api.h`; `llhttp.c` (generated by llparse) restyled with a script that keeps the same `objdump -d`; the span fields typed; without the wasm build, `llhttp_alloc ()`, `llhttp_free ()`, `llhttp_method_name ()`, `llhttp_status_name ()` and the header value relaxed flag; the methods are the ones of `cerver/http/requests/method.h` |
| [Jansson](https://github.com/akheron/jansson) | `include/cerver/http/json/`, `src/cerver/http/json/` | 2.13 | MIT, Copyright (c) 2009-2016 Petri Lehtinen | The style of cerver; the hash seed from the entropy of the kernel; a memory limit for each parse; the numbers without the locale; its internal methods are not exported |
| [libjwt](https://github.com/benmcollins/libjwt) | `include/cerver/http/jwt/`, `src/cerver/http/jwt/` | 1.12 | MPL 2.0, Copyright (C) 2015-2018 Ben Collins | The style of cerver, OpenSSL 3 only; the signatures with the keys of `jwt/key.{h,c}` (cerver's own), the canonical base64url of `utils/base64.c`, the HMAC compared in constant time, the names of the algorithms of RFC 7518 |
| [sha-2](https://github.com/amosnier/sha-2) | `src/cerver/utils/sha256.c` | Imported in 2019 | Unlicense or Zero Clause BSD, Alain Mosnier | The SHA-256 of the session ids and of the lobbies, behind `cerver/utils/sha256.h` |
| [fastbase64](https://github.com/lemire/fastbase64) | `src/cerver/utils/base64.c` | Imported in 2020 | BSD 2-Clause, Copyright (c) 2015-2016, Wojciech Muła, Alfred Klomp, Daniel Lemire; the scalar code of [stringencoders](https://github.com/client9/stringencoders) (modp_b64), BSD, Copyright (c) 2005-2007, Nick Galbreath; the AVX2 code of [base64simd](https://github.com/WojciechMula/base64simd), BSD 2-Clause, Copyright (c) 2015-2018, Wojciech Muła, and of [base64](https://github.com/aklomp/base64), BSD 2-Clause, Copyright (c) 2013-2022, Alfred Klomp | The canonical base64url encode and decode of cerver (2.0b-67), the AVX2 code only compiled with `__AVX2__` |
